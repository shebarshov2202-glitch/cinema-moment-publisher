# Cinema Moment Publisher

VK Mini App для создания отложенных постов Cinema Moment.

## Что умеет
- пользовательская авторизация VK через VK Bridge;
- проверка доступа к сообществу;
- загрузка ровно двух изображений;
- предпросмотр текста;
- создание `wall.post` от имени сообщества;
- отложенная публикация через `publish_date`;
- время трактуется как Москва (UTC+3).

## Безопасность
Access token не хранится в репозитории, localStorage, cookies или файлах. Он существует только в памяти открытой вкладки.

## VK Mini App
App ID: `54720636`

## Публикация через GitHub Pages
В GitHub: Settings → Pages → Deploy from a branch → `main` / `(root)`.
После появления HTTPS URL его нужно указать в настройках размещения VK Mini App для мобильной и десктопной WebView.

## Тест
Перед массовой загрузкой создать один отложенный пост и проверить его в разделе «Отложенные» сообщества.
